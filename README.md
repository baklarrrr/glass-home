# Bakar Home

<sub>BAKAR STUDIO / PERSONAL EXPERIMENT</sub>

A compact home screen for studio information and app links, designed for wearable displays.

## Status

Experimental preview. Physical-device behavior is not fully verified. Connected studio features require additional components that are not included in this public interface repository.

[Project page](https://baklarrrr.github.io/glass-home/) | [Bakar Studio](https://bakar.ca/)
